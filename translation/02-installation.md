# نصب

هرجا در این کتاب به «پایتونِ ۳» اشاره می‌کنیم، منظورمان هر نسخه‌ای از [پایتون](https://www.python.org/downloads/) است که برابر یا بزرگ‌تر از نسخهٔ 3.6.0 باشد.

## نصب روی ویندوز

به <https://www.python.org/downloads/> بروید و آخرین نسخه را دانلود کنید. نصب درست مانندِ هر نرم‌افزارِ دیگرِ مبتنی‌بر ویندوز است.

توجه کنید که اگر نسخهٔ ویندوزِ شما پیش از Vista است، باید [تنها پایتونِ ۳٫۴ را دانلود کنید](https://www.python.org/downloads/windows/)، چون نسخه‌های بعدی به نسخه‌های تازه‌ترِ ویندوز نیاز دارند.

> **هشدار:** حتماً گزینهٔ `Add Python 3 to PATH` را تیک بزنید.

برای تغییرِ محلِ نصب، روی `Customize installation` کلیک کنید، سپس `Next` و مسیرِ نصب (مثلاً `C:\python3`، یا هر مسیرِ مناسبِ دیگر) را وارد کنید.

اگر گزینهٔ `Add Python 3 to PATH` را پیش‌تر تیک نزده بودید، گزینهٔ `Add Python to environment variables` را تیک بزنید. این همان کاری را می‌کند که `Add Python 3 to PATH` در نخستین صفحهٔ نصب انجام می‌دهد.

می‌توانید برگزینید که Launcher برای همهٔ کاربران نصب شود یا نه؛ تفاوتِ چندانی ندارد. Launcher برای جابه‌جایی میانِ نسخه‌های گوناگونِ نصب‌شدهٔ پایتون به کار می‌رود.

اگر مسیرِ شما درست تنظیم نشد (یعنی گزینه‌های `Add Python 3 to PATH` یا `Add Python to environment variables` را نزدید)، گام‌های بخشِ بعد («اعلانِ DOS») را برای رفعِ آن دنبال کنید. در غیرِ این صورت، به بخشِ «اجرای اعلانِ پایتون روی ویندوز» در همین سند بروید.

> **نکته:** برای کسانی که پیش‌تر برنامه‌نویسی می‌دانند: اگر با Docker آشنایید، [Python in Docker](https://hub.docker.com/_/python/) و [Docker on Windows](https://docs.docker.com/windows/) را ببینید.

### اعلانِ DOS

اگر می‌خواهید بتوانید پایتون را از خطِ فرمانِ ویندوز، یعنی اعلانِ DOS، به کار ببرید، باید متغیرِ `PATH` را به‌درستی تنظیم کنید.

برای ویندوزِ ۷ و ۸:

- روی `Computer` در دسکتاپ راست‌کلیک کنید و `Properties` را برگزینید، یا `Start` را بزنید و `Control Panel` ‏← `System and Security` ‏← `System` را برگزینید. در سمتِ چپ روی `Advanced system settings` کلیک کنید و سپس زبانهٔ `Advanced` را بزنید. در پایین روی `Environment Variables` کلیک کنید و در بخشِ `System variables` دنبالِ متغیرِ `PATH` بگردید، آن را انتخاب و سپس `Edit` را بزنید.
- به انتهای مقدارِ متغیر بروید و `;C:\Python3` را به انتهای آنچه از پیش هست بیفزایید (لطفاً بررسی کنید که این پوشه وجود دارد؛ برای نسخه‌های تازه‌ترِ پایتون متفاوت خواهد بود). البته از نامِ پوشهٔ مناسب استفاده کنید.
- اگر مقدار `%SystemRoot%\system32;` بود، اکنون `%SystemRoot%\system32;C:\Python3` خواهد شد.
- `OK` را بزنید؛ تمام است. نیازی به راه‌اندازیِ دوباره نیست، هرچند شاید لازم باشد خطِ فرمان را ببندید و دوباره باز کنید.

برای ویندوزِ ۱۰:

منویِ Start ویندوز ‏← `Settings` ‏← `About` ‏← `System Info` (این کاملاً در سمتِ راست است) ‏← `Advanced System Settings` ‏← `Environment Variables` (این نزدیکِ پایین است) ‏← (سپس متغیرِ `Path` را برجسته کنید و `Edit` را بزنید) ‏← `New` ‏← (مسیرِ نصبِ پایتونتان را تایپ کنید. برای مثال `C:\Python3\`).

### اجرای اعلانِ پایتون روی ویندوز

کاربرانِ ویندوز اگر [متغیرِ `PATH` را به‌درستی تنظیم کرده باشند](#اعلانِ-dos)، می‌توانند مفسر را در خطِ فرمان اجرا کنند.

برای بازکردنِ ترمینال در ویندوز، دکمهٔ Start را بزنید و `Run` را کلیک کنید. در کادرِ گفت‌وگو `cmd` را تایپ کنید و کلیدِ `[enter]` را بزنید. سپس `python` را تایپ کنید و مطمئن شوید هیچ خطایی رخ نمی‌دهد.

## نصب روی Mac OS X

کاربرانِ Mac OS X از [Homebrew](http://brew.sh) استفاده کنند: `brew install python3`.

برای راستی‌آزمایی، ترمینال را با فشردنِ کلیدهای `[Command + Space]` (برای بازکردنِ جستجوی Spotlight) باز کنید، `Terminal` را تایپ کنید و کلیدِ `[enter]` را بزنید. حالا `python3` را اجرا کنید و مطمئن شوید هیچ خطایی رخ نمی‌دهد.

## نصب روی GNU/Linux

کاربرانِ GNU/Linux از مدیرِ بستهٔ توزیعِ خود برای نصبِ پایتونِ ۳ استفاده کنند؛ برای مثال روی Debian و Ubuntu: ‏`sudo apt-get update && sudo apt-get install python3`.

برای راستی‌آزمایی، ترمینال را با بازکردنِ برنامهٔ `Terminal`، یا با فشردنِ `Alt + F2` و واردکردنِ `gnome-terminal` باز کنید. اگر این کار نکرد، لطفاً به مستنداتِ توزیعِ GNU/Linux خود مراجعه کنید. حالا `python3` را اجرا کنید و مطمئن شوید هیچ خطایی رخ نمی‌دهد.

می‌توانید با اجرای فرمانِ زیر نسخهٔ پایتون را روی صفحه ببینید:

```
$ python3 -V
Python 3.6.0
```

> **نکته:** نمادِ `$` اعلانِ پوسته (shell) است. بسته به تنظیماتِ سیستم‌عاملِ کامپیوترِ شما متفاوت خواهد بود؛ از این رو من اعلان را تنها با نمادِ `$` نشان می‌دهم.

> **هشدار:** بسته به نسخهٔ نرم‌افزارِ پایتونِ نصب‌شده روی کامپیوترتان، خروجی ممکن است روی کامپیوترِ شما متفاوت باشد.
