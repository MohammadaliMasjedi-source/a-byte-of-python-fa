# ساختارهای داده

ساختارهای داده دقیقاً همان چیزی هستند که از نامشان پیداست: *ساختارهایی* که می‌توانند چند *داده* را کنار هم نگه دارند. به بیان دیگر، از آنها برای ذخیره‌کردنِ گردایه‌ای از داده‌های مرتبط استفاده می‌کنیم.

پایتون چهار ساختارِ دادهٔ درون‌ساخته دارد: *فهرست، چندتایی، دیکشنری و مجموعه*. در این فصل می‌بینیم هرکدام چگونه به کار می‌روند و چطور کارمان را آسان‌تر می‌کنند.

## فهرست

`list` ساختارِ داده‌ای است که گردایه‌ای مرتب از عضوها را نگه می‌دارد؛ یعنی می‌توانید یک *دنباله* از عضوها را درونِ فهرست ذخیره کنید. برای تصورش به فهرستِ خرید فکر کنید: نامِ چیزهایی که باید بخرید معمولاً هرکدام در یک سطر نوشته می‌شوند، اما در فهرستِ پایتون میانِ آنها ویرگول می‌گذارید.

عضوهای فهرست باید میانِ کروشه‌ها قرار بگیرند تا پایتون بفهمد یک فهرست تعریف می‌کنید. پس از ساختنِ فهرست می‌توانید به آن عضو بیفزایید، عضوی را حذف کنید یا در آن به‌دنبالِ چیزی بگردید. چون می‌توان عضوها را افزود و حذف کرد، می‌گوییم فهرست نوعِ داده‌ای *تغییرپذیر* (mutable) است؛ یعنی محتوای آن را می‌توان تغییر داد.

## آشناییِ کوتاه با شیءها و کلاس‌ها

تا اینجا گفت‌وگو دربارهٔ شیءها و کلاس‌ها را عقب انداخته‌ام، اما اکنون برای آنکه فهرست‌ها را بهتر بفهمید به توضیحی کوتاه نیاز داریم. این موضوع را در فصلی دیگر با جزئیات بررسی خواهیم کرد.

فهرست نمونه‌ای از به‌کارگیریِ شیءها و کلاس‌هاست. وقتی متغیری مانندِ `i` می‌سازیم و مقداری مانندِ عددِ صحیحِ `5` را به آن نسبت می‌دهیم، می‌توانید آن را ساختنِ یک *شیء* (یا نمونه) به نامِ `i` از *کلاس* (یا نوعِ) `int` در نظر بگیرید. برای درکِ بهتر می‌توانید `help(int)` را بخوانید.

یک کلاس می‌تواند *متد* هم داشته باشد؛ یعنی تابع‌هایی که فقط برای استفاده در ارتباط با همان کلاس تعریف شده‌اند. تنها هنگامی می‌توانید از این قابلیت‌ها استفاده کنید که شیئی از آن کلاس داشته باشید. برای مثال، پایتون برای کلاسِ `list` متدِ `append` را فراهم می‌کند که عضوی را به انتهای فهرست می‌افزاید. بنابراین `mylist.append('an item')` این رشته را به فهرستِ `mylist` اضافه می‌کند. به نمادِ نقطه‌ای که برای دسترسی به متدهای شیء به کار رفته توجه کنید.

کلاس همچنین می‌تواند *فیلد* داشته باشد؛ فیلد چیزی جز متغیری نیست که فقط برای همان کلاس تعریف شده است. این متغیرها یا نام‌ها نیز تنها از راهِ یک شیء از آن کلاس در دسترس‌اند. برای دسترسی به فیلدها هم از نمادِ نقطه استفاده می‌کنیم، مانندِ `mylist.field`.

مثال (با نامِ `ds_using_list.py` ذخیره کنید):

```python
# This is my shopping list
shoplist = ['apple', 'mango', 'carrot', 'banana']

print('I have', len(shoplist), 'items to purchase.')

print('These items are:', end=' ')
for item in shoplist:
    print(item, end=' ')

print('\nI also have to buy rice.')
shoplist.append('rice')
print('My shopping list is now', shoplist)

print('I will sort my list now')
shoplist.sort()
print('Sorted shopping list is', shoplist)

print('The first item I will buy is', shoplist[0])
olditem = shoplist[0]
del shoplist[0]
print('I bought the', olditem)
print('My shopping list is now', shoplist)
```

خروجی:

```
$ python ds_using_list.py
I have 4 items to purchase.
These items are: apple mango carrot banana
I also have to buy rice.
My shopping list is now ['apple', 'mango', 'carrot', 'banana', 'rice']
I will sort my list now
Sorted shopping list is ['apple', 'banana', 'carrot', 'mango', 'rice']
The first item I will buy is apple
I bought the apple
My shopping list is now ['banana', 'carrot', 'mango', 'rice']
```

**چگونه کار می‌کند**

متغیرِ `shoplist` فهرستِ خریدِ کسی است که به بازار می‌رود. در `shoplist` فقط رشته‌هایی را نگه می‌داریم که نامِ کالاهای موردنیازند، اما می‌توان *هر نوع شیئی* را به یک فهرست افزود؛ از عدد گرفته تا حتی فهرستی دیگر.

برای پیمایشِ عضوهای فهرست از حلقهٔ `for..in` هم استفاده کرده‌ایم. تا اینجا احتمالاً متوجه شده‌اید که فهرست نیز نوعی دنباله است. ویژگی‌های دنباله‌ها را در [بخشی دیگر](#دنباله) خواهیم دید.

به آرگومانِ `end` در فراخوانیِ تابعِ `print` توجه کنید. این آرگومان می‌گوید خروجی به‌جای رفتن به سطرِ بعد، با یک فاصله پایان یابد.

سپس با متدِ `append` شیءِ فهرست، همان‌طور که پیش‌تر گفته شد، عضوی را به آن می‌افزاییم. بعد، خودِ فهرست را به تابعِ `print` می‌دهیم تا محتوایش مرتب چاپ شود و مطمئن شویم عضو واقعاً افزوده شده است.

پس از آن، با متدِ `sort` فهرست را مرتب می‌کنیم. نکتهٔ مهم این است که این متد خودِ فهرست را تغییر می‌دهد و فهرستِ تغییریافتهٔ جداگانه‌ای برنمی‌گرداند؛ این رفتار با رشته‌ها فرق دارد. منظورمان از تغییرپذیربودنِ فهرست‌ها و تغییرناپذیربودنِ رشته‌ها همین است.

سپس، وقتی خریدِ یک کالا تمام شد، می‌خواهیم آن را از فهرست حذف کنیم. این کار را با دستورِ `del` انجام می‌دهیم: عضوِ موردنظر را مشخص می‌کنیم و `del` آن را حذف می‌کند. چون می‌خواهیم نخستین عضو را برداریم، از `del shoplist[0]` استفاده می‌کنیم؛ به یاد داشته باشید که شمارش در پایتون از صفر آغاز می‌شود.

برای دیدنِ همهٔ متدهای تعریف‌شده برای شیءِ فهرست، `help(list)` را ببینید.

## چندتایی

چندتایی‌ها (tuples) چند شیء را کنار هم نگه می‌دارند. آنها را شبیهِ فهرست‌ها در نظر بگیرید، اما بدونِ قابلیت‌های گسترده‌ای که کلاسِ فهرست فراهم می‌کند. ویژگیِ مهمِ چندتایی‌ها این است که مانندِ رشته‌ها *تغییرناپذیر* (immutable) هستند؛ یعنی نمی‌توانید آنها را تغییر دهید.

برای تعریفِ چندتایی، عضوها را با ویرگول از هم جدا می‌کنیم و می‌توانیم آنها را میانِ یک جفت پرانتزِ اختیاری قرار دهیم.

چندتایی معمولاً هنگامی به کار می‌رود که یک دستور یا تابعِ تعریف‌شده به‌دستِ کاربر بتواند با خیالِ آسوده فرض کند گردایهٔ مقدارها (یعنی چندتاییِ مقدارهای به‌کاررفته) در طولِ کار تغییر نخواهد کرد.

مثال (با نامِ `ds_using_tuple.py` ذخیره کنید):

```python
# I would recommend always using parentheses
# to indicate start and end of tuple
# even though parentheses are optional.
# Explicit is better than implicit.
zoo = ('python', 'elephant', 'penguin')
print('Number of animals in the zoo is', len(zoo))

new_zoo = 'monkey', 'camel', zoo    # parentheses not required but are a good idea
print('Number of cages in the new zoo is', len(new_zoo))
print('All animals in new zoo are', new_zoo)
print('Animals brought from old zoo are', new_zoo[2])
print('Last animal brought from old zoo is', new_zoo[2][2])
print('Number of animals in the new zoo is',
      len(new_zoo)-1+len(new_zoo[2]))
```

خروجی:

```
$ python ds_using_tuple.py
Number of animals in the zoo is 3
Number of cages in the new zoo is 3
All animals in new zoo are ('monkey', 'camel', ('python', 'elephant', 'penguin'))
Animals brought from old zoo are ('python', 'elephant', 'penguin')
Last animal brought from old zoo is penguin
Number of animals in the new zoo is 5
```

**چگونه کار می‌کند**

متغیرِ `zoo` به یک چندتایی از عضوها اشاره می‌کند. می‌بینیم که تابعِ `len` طولِ چندتایی را به دست می‌آورد؛ این موضوع نشان می‌دهد چندتایی نیز یک [دنباله](#دنباله) است.

چون باغ‌وحشِ قدیمی بسته می‌شود، حیوان‌ها را به باغ‌وحشی تازه منتقل می‌کنیم. از این رو، چندتاییِ `new_zoo` هم حیوان‌هایی را که از پیش آنجا بوده‌اند در بر دارد و هم حیوان‌هایی را که از باغ‌وحشِ قدیمی آورده‌ایم. اگر از مثال فاصله بگیریم، نکته این است که چندتاییِ درونِ یک چندتایی هویتِ خودش را از دست نمی‌دهد.

درست مانندِ فهرست‌ها، با نوشتنِ جایگاهِ عضو میانِ یک جفت کروشه به عضوهای چندتایی دسترسی پیدا می‌کنیم. به این کار *اندیس‌گذاری* (indexing) می‌گویند. با `new_zoo[2]` به سومین عضوِ `new_zoo` دسترسی می‌یابیم و با `new_zoo[2][2]` سومین عضوِ درونِ سومین عضوِ آن را می‌گیریم. وقتی این الگو را بفهمید، کار بسیار ساده است.

> **چندتایی با صفر یا یک عضو**
>
> یک جفت پرانتزِ خالی، مانندِ `myempty = ()`، چندتاییِ خالی می‌سازد. اما ساختنِ چندتاییِ تک‌عضوی کمی ظرافت دارد. باید پس از نخستین و تنها عضو یک ویرگول بگذارید تا پایتون بتواند آن را از پرانتزهایی که دورِ یک شیء در عبارت آمده‌اند تشخیص دهد. برای نمونه، اگر منظورتان چندتایی‌ای شاملِ عددِ `2` است باید `singleton = (2 , )` بنویسید.

> **نکته‌ای برای برنامه‌نویسانِ Perl**
>
> فهرستِ درونِ یک فهرست هویتِ خود را از دست نمی‌دهد؛ یعنی برخلافِ Perl، فهرست‌ها تخت نمی‌شوند. همین قاعده برای چندتاییِ درونِ چندتایی، چندتاییِ درونِ فهرست، فهرستِ درونِ چندتایی و حالت‌های مشابه برقرار است. از دیدِ پایتون، اینها فقط شیءهایی هستند که با کمکِ شیئی دیگر ذخیره شده‌اند.

## دیکشنری

دیکشنری شبیهِ دفترچهٔ نشانی است: با دانستنِ نامِ یک نفر می‌توانید نشانی یا اطلاعاتِ تماسش را پیدا کنید. به بیان دیگر، *کلیدها* (نام‌ها) را به *مقدارها* (جزئیات) پیوند می‌دهیم. کلید باید یکتا باشد؛ همان‌طور که اگر دو نفر دقیقاً یک نام داشته باشند، فقط با دانستنِ نام نمی‌توانید اطلاعاتِ درست را پیدا کنید.

برای کلیدهای دیکشنری تنها می‌توان از شیءهای تغییرناپذیر، مانندِ رشته‌ها، استفاده کرد؛ اما مقدارها می‌توانند تغییرپذیر یا تغییرناپذیر باشند. در عمل بهتر است برای کلیدها از شیءهای ساده استفاده کنید.

جفت‌های کلید و مقدار را با نمادِ `d = {key1 : value1, key2 : value2 }` مشخص می‌کنیم. میانِ کلید و مقدار دونقطه می‌آید، جفت‌ها با ویرگول از هم جدا می‌شوند و همهٔ آنها میانِ یک جفت آکولاد قرار می‌گیرند.

به یاد داشته باشید که جفت‌های کلید-مقدار در دیکشنری ترتیبِ معینی ندارند. اگر ترتیبِ خاصی می‌خواهید، باید پیش از استفاده خودتان آنها را مرتب کنید.

دیکشنری‌هایی که به کار می‌برید نمونه‌ها یا شیءهایی از کلاسِ `dict` هستند.

مثال (با نامِ `ds_using_dict.py` ذخیره کنید):

```python
# 'ab' is short for 'a'ddress'b'ook

ab = {
    'Swaroop': 'swaroop@swaroopch.com',
    'Larry': 'larry@wall.org',
    'Matsumoto': 'matz@ruby-lang.org',
    'Spammer': 'spammer@hotmail.com'
}

print("Swaroop's address is", ab['Swaroop'])

# Deleting a key-value pair
del ab['Spammer']

print('\nThere are {} contacts in the address-book\n'.format(len(ab)))

for name, address in ab.items():
    print('Contact {} at {}'.format(name, address))

# Adding a key-value pair
ab['Guido'] = 'guido@python.org'

if 'Guido' in ab:
    print("\nGuido's address is", ab['Guido'])
```

خروجی:

```
$ python ds_using_dict.py
Swaroop's address is swaroop@swaroopch.com

There are 3 contacts in the address-book

Contact Swaroop at swaroop@swaroopch.com
Contact Matsumoto at matz@ruby-lang.org
Contact Larry at larry@wall.org

Guido's address is guido@python.org
```

**چگونه کار می‌کند**

دیکشنریِ `ab` را با همان نمادی که پیش‌تر دیدیم می‌سازیم. سپس با مشخص‌کردنِ کلید در عملگرِ اندیس‌گذاری به جفت‌های کلید-مقدار دسترسی پیدا می‌کنیم؛ همان عملگری که برای فهرست‌ها و چندتایی‌ها به کار بردیم. به سادگیِ این نحو توجه کنید.

با دوستِ قدیمی‌مان، دستورِ `del`، می‌توانیم جفت‌های کلید-مقدار را حذف کنیم. کافی است دیکشنری و کلیدِ موردنظر را با عملگرِ اندیس‌گذاری به `del` بدهیم. برای این کار لازم نیست مقدارِ متناظر با کلید را بدانیم.

سپس با متدِ `items` دیکشنری به تک‌تکِ جفت‌های کلید-مقدار دسترسی پیدا می‌کنیم. این متد فهرستی از چندتایی‌ها برمی‌گرداند که هر چندتایی یک جفت عضو دارد: نخست کلید و سپس مقدار. در هر دورِ حلقهٔ `for..in` این جفت را می‌گیریم، عضوهایش را به‌ترتیب به متغیرهای `name` و `address` نسبت می‌دهیم و آنها را در بلوکِ حلقه چاپ می‌کنیم.

برای افزودنِ جفتِ تازه کافی است با عملگرِ اندیس‌گذاری به یک کلید دسترسی پیدا کنیم و مقداری به آن نسبت دهیم؛ همان کاری که در مثال برای Guido انجام داده‌ایم.

با عملگرِ `in` می‌توانیم بررسی کنیم که یک جفتِ کلید-مقدار وجود دارد یا نه.

برای فهرستِ متدهای کلاسِ `dict`، `help(dict)` را ببینید.

> **آرگومان‌های کلیدواژه‌ای و دیکشنری‌ها**
>
> اگر در تابع‌هایتان از آرگومان‌های کلیدواژه‌ای استفاده کرده‌اید، در واقع از دیکشنری‌ها هم استفاده کرده‌اید. جفتِ کلید-مقدار را در فهرستِ پارامترهای تعریفِ تابع مشخص می‌کنید و وقتی درونِ تابع به متغیرها دسترسی دارید، در اصل کلیدی را در یک دیکشنری می‌خوانید؛ این دیکشنری در اصطلاحِ طراحیِ کامپایلر *جدولِ نمادها* (symbol table) نام دارد.

## دنباله

فهرست‌ها، چندتایی‌ها و رشته‌ها نمونه‌هایی از دنباله‌اند. اما دنباله چیست و چه ویژگیِ خاصی دارد؟

ویژگی‌های اصلیِ دنباله‌ها *آزمونِ عضویت*، یعنی عبارت‌های `in` و `not in`، و *عملیاتِ اندیس‌گذاری* هستند که به ما امکان می‌دهند مستقیماً عضوِ مشخصی از دنباله را بگیریم.

سه نوعِ دنباله‌ای که نام بردیم — فهرست، چندتایی و رشته — عملیاتِ *برش* (slicing) هم دارند؛ با برش می‌توانیم بخشی از دنباله را جدا کنیم.

مثال (با نامِ `ds_seq.py` ذخیره کنید):

```python
shoplist = ['apple', 'mango', 'carrot', 'banana']
name = 'swaroop'

# Indexing or 'Subscription' operation #
print('Item 0 is', shoplist[0])
print('Item 1 is', shoplist[1])
print('Item 2 is', shoplist[2])
print('Item 3 is', shoplist[3])
print('Item -1 is', shoplist[-1])
print('Item -2 is', shoplist[-2])
print('Character 0 is', name[0])

# Slicing on a list #
print('Item 1 to 3 is', shoplist[1:3])
print('Item 2 to end is', shoplist[2:])
print('Item 1 to -1 is', shoplist[1:-1])
print('Item start to end is', shoplist[:])

# Slicing on a string #
print('characters 1 to 3 is', name[1:3])
print('characters 2 to end is', name[2:])
print('characters 1 to -1 is', name[1:-1])
print('characters start to end is', name[:])
```

خروجی:

```
$ python ds_seq.py
Item 0 is apple
Item 1 is mango
Item 2 is carrot
Item 3 is banana
Item -1 is banana
Item -2 is carrot
Character 0 is s
Item 1 to 3 is ['mango', 'carrot']
Item 2 to end is ['carrot', 'banana']
Item 1 to -1 is ['mango', 'carrot']
Item start to end is ['apple', 'mango', 'carrot', 'banana']
characters 1 to 3 is wa
characters 2 to end is aroop
characters 1 to -1 is waroo
characters start to end is swaroop
```

**چگونه کار می‌کند**

نخست می‌بینیم چگونه با اندیس‌ها عضوهای جداگانهٔ یک دنباله را بگیریم. به این کار عملیاتِ *زیرنویس‌گذاری* (subscription) هم گفته می‌شود. هرگاه مانندِ مثال عددی را میانِ کروشه‌های پس از دنباله بنویسید، پایتون عضوِ جایگاهِ متناظر با آن عدد را برمی‌گرداند. به یاد داشته باشید که شمارش در پایتون از صفر آغاز می‌شود؛ بنابراین `shoplist[0]` نخستین عضو و `shoplist[3]` چهارمین عضوِ دنبالهٔ `shoplist` را می‌گیرد.

اندیس می‌تواند منفی هم باشد. در این حالت، جایگاه از انتهای دنباله محاسبه می‌شود. پس `shoplist[-1]` به آخرین عضو و `shoplist[-2]` به عضوِ یکی‌مانده‌به‌آخر اشاره می‌کند.

برای برش، نامِ دنباله را می‌نویسیم و پس از آن یک جفت عددِ اختیاری را که با دونقطه از هم جدا شده‌اند میانِ کروشه می‌آوریم. این شکل بسیار شبیهِ اندیس‌گذاری است. به یاد داشته باشید که عددها اختیاری‌اند، اما دونقطه اجباری است.

عددِ نخست، یعنی عددِ پیش از دونقطه، جایگاهِ آغازِ برش را تعیین می‌کند و عددِ دوم جایگاهی را نشان می‌دهد که برش پیش از آن متوقف می‌شود. اگر عددِ نخست نوشته نشود، پایتون از ابتدای دنباله آغاز می‌کند؛ اگر عددِ دوم نوشته نشود، تا پایانِ دنباله پیش می‌رود. برشِ برگشتی از جایگاهِ آغاز *شروع می‌شود* و درست پیش از جایگاهِ پایان تمام می‌شود؛ یعنی عضوِ آغاز در برش هست، اما عضوِ پایان نیست.

بنابراین `shoplist[1:3]` برشی را برمی‌گرداند که از جایگاهِ ۱ شروع می‌شود، جایگاهِ ۲ را در بر می‌گیرد و پیش از جایگاهِ ۳ می‌ایستد؛ در نتیجه برشی دو عضوی به دست می‌آید. همچنین `shoplist[:]` نسخه‌ای کپی‌شده از کلِ دنباله را برمی‌گرداند.

می‌توانید با جایگاه‌های منفی هم برش بزنید. عددهای منفی جایگاه را از انتهای دنباله می‌شمارند. برای مثال، `shoplist[:-1]` برشی می‌دهد که همهٔ عضوها جز عضوِ آخر را در بر دارد.

آرگومانِ سومی هم می‌توان برای برش نوشت که *گام* (step) برش را تعیین می‌کند. مقدارِ پیش‌فرضِ گام ۱ است:

```pycon
>>> shoplist = ['apple', 'mango', 'carrot', 'banana']
>>> shoplist[::1]
['apple', 'mango', 'carrot', 'banana']
>>> shoplist[::2]
['apple', 'carrot']
>>> shoplist[::3]
['apple', 'banana']
>>> shoplist[::-1]
['banana', 'carrot', 'mango', 'apple']
```

توجه کنید که با گامِ ۲، عضوهای جایگاهِ ۰، ۲ و به همین ترتیب را می‌گیریم. با گامِ ۳ هم عضوهای جایگاهِ ۰، ۳ و به همین ترتیب به دست می‌آیند.

ترکیب‌های گوناگونِ این برش‌ها را در مفسرِ تعاملیِ پایتون امتحان کنید تا نتیجه را بی‌درنگ ببینید (یعنی در همان اعلان). ویژگیِ بسیار خوبِ دنباله‌ها این است که با فهرست‌ها، چندتایی‌ها و رشته‌ها به یک شیوه کار می‌کنید.

## مجموعه

مجموعه‌ها (sets) گردایه‌هایی *نامرتب* از شیءهای ساده‌اند. هنگامی از آنها استفاده می‌کنیم که وجودداشتنِ یک شیء در گردایه مهم‌تر از ترتیبِ عضوها یا تعدادِ تکرارِ آن باشد.

با مجموعه‌ها می‌توانید عضویت را بیازمایید، بررسی کنید مجموعه‌ای زیرمجموعهٔ مجموعه‌ای دیگر هست یا نه، اشتراکِ دو مجموعه را به دست آورید و کارهای مشابه انجام دهید.

```pycon
>>> bri = set(['brazil', 'russia', 'india'])
>>> 'india' in bri
True
>>> 'usa' in bri
False
>>> bric = bri.copy()
>>> bric.add('china')
>>> bric.issuperset(bri)
True
>>> bri.remove('russia')
>>> bri & bric # OR bri.intersection(bric)
{'brazil', 'india'}
```

**چگونه کار می‌کند**

اگر نظریهٔ مقدماتیِ مجموعه‌ها را از ریاضیِ مدرسه به یاد داشته باشید، این مثال کمابیش خودگویاست. اگر نه، برای درکِ بهترِ کاربردِ مجموعه‌ها در پایتون دربارهٔ «نظریهٔ مجموعه‌ها» و «نمودارِ ون» جست‌وجو کنید.

## ارجاع‌ها

وقتی شیئی می‌سازید و آن را به متغیری نسبت می‌دهید، متغیر فقط به آن شیء *ارجاع* می‌دهد و خودِ شیء نیست. نامِ متغیر به بخشی از حافظهٔ رایانه اشاره می‌کند که شیء در آن ذخیره شده است. به این کار *مقیدکردنِ* (binding) نام به شیء می‌گویند.

معمولاً لازم نیست نگرانِ این موضوع باشید، اما ارجاع‌ها اثرِ ظریفی دارند که باید از آن آگاه باشید:

مثال (با نامِ `ds_reference.py` ذخیره کنید):

```python
print('Simple Assignment')
shoplist = ['apple', 'mango', 'carrot', 'banana']
# mylist is just another name pointing to the same object!
mylist = shoplist

# I purchased the first item, so I remove it from the list
del shoplist[0]

print('shoplist is', shoplist)
print('mylist is', mylist)
# Notice that both shoplist and mylist both print
# the same list without the 'apple' confirming that
# they point to the same object

print('Copy by making a full slice')
# Make a copy by doing a full slice
mylist = shoplist[:]
# Remove first item
del mylist[0]

print('shoplist is', shoplist)
print('mylist is', mylist)
# Notice that now the two lists are different
```

خروجی:

```
$ python ds_reference.py
Simple Assignment
shoplist is ['mango', 'carrot', 'banana']
mylist is ['mango', 'carrot', 'banana']
Copy by making a full slice
shoplist is ['mango', 'carrot', 'banana']
mylist is ['carrot', 'banana']
```

**چگونه کار می‌کند**

بیشترِ توضیح در توضیح‌های (comments) درونِ کد آمده است.

به یاد داشته باشید که برای کپی‌کردنِ یک فهرست یا دنباله‌ها و شیءهای پیچیدهٔ مشابه — نه شیءهای ساده‌ای مانندِ عددهای صحیح — باید با عملیاتِ برش یک کپی بسازید. اگر فقط نامِ متغیر را به نامی دیگر نسبت دهید، هر دو نام به یک شیء ارجاع خواهند داد و اگر حواستان نباشد، ممکن است به دردسر بیفتید.

> **نکته‌ای برای برنامه‌نویسانِ Perl**
>
> دستورِ انتساب برای فهرست‌ها یک کپی **نمی‌سازد**. برای کپی‌کردنِ دنباله باید از عملیاتِ برش استفاده کنید.

## نکته‌های بیشتر دربارهٔ رشته‌ها

پیش‌تر رشته‌ها را با جزئیات بررسی کرده‌ایم. دیگر چه چیزی برای آموختن مانده است؟ آیا می‌دانستید رشته‌ها نیز شیء هستند و متدهایی دارند که کارهایی از بررسیِ بخشی از رشته تا زدودنِ فاصله‌ها را انجام می‌دهند؟ در واقع، از پیش یکی از متدهای رشته، یعنی `format`، را به کار برده‌اید.

همهٔ رشته‌هایی که در برنامه‌ها استفاده می‌کنید شیءهایی از کلاسِ `str` هستند. مثالِ بعد چند متدِ سودمندِ این کلاس را نشان می‌دهد. برای فهرستِ کاملِ متدها، `help(str)` را ببینید.

مثال (با نامِ `ds_str_methods.py` ذخیره کنید):

```python
# This is a string object
name = 'Swaroop'

if name.startswith('Swa'):
    print('Yes, the string starts with "Swa"')

if 'a' in name:
    print('Yes, it contains the string "a"')

if name.find('war') != -1:
    print('Yes, it contains the string "war"')

delimiter = '_*_'
mylist = ['Brazil', 'Russia', 'India', 'China']
print(delimiter.join(mylist))
```

خروجی:

```
$ python ds_str_methods.py
Yes, the string starts with "Swa"
Yes, it contains the string "a"
Yes, it contains the string "war"
Brazil_*_Russia_*_India_*_China
```

**چگونه کار می‌کند**

اینجا چندین متدِ رشته را در عمل می‌بینیم. متدِ `startswith` بررسی می‌کند که آیا رشته با رشتهٔ داده‌شده آغاز می‌شود یا نه. عملگرِ `in` هم بررسی می‌کند که رشته‌ای مشخص بخشی از رشتهٔ دیگر هست یا نه.

متدِ `find` جایگاهِ زیررشتهٔ داده‌شده را پیدا می‌کند و اگر نتواند آن را بیابد، `-1` برمی‌گرداند. کلاسِ `str` متدِ سودمندِ `join` را نیز دارد: این متد عضوهای یک دنباله را به هم می‌پیوندد، رشته را میانِ آنها به‌عنوانِ جداکننده می‌گذارد و رشتهٔ بزرگ‌تری برمی‌گرداند.
